# Zehnora whole-asset sale room

This directory prepares one serious sale/assignment of the complete Zehnora asset.
It is not a retail licensing program and does not replace licensed legal advice.

## Seller: start here

1. [`SELLER_DECISION_BRIEF_AR.md`](SELLER_DECISION_BRIEF_AR.md) — plain-Arabic
   explanation, recommended price, and decisions required.
2. [`MIT_LICENSE_IMPACT_MEMO.md`](MIT_LICENSE_IMPACT_MEMO.md) — historical-license
   facts, practical sale effect, and counsel questions.
3. [`VALUATION_AND_FAST_OFFER.md`](VALUATION_AND_FAST_OFFER.md) — USD 2,500 ask,
   negotiation range, confidential floor, and terms.
4. [`FAST_SALE_RUNBOOK.md`](FAST_SALE_RUNBOOK.md) — 14-day process from legal
   intake through escrow and acceptance.
