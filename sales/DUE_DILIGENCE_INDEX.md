# Buyer due-diligence index

## Corporate, title, and IP — seller/counsel supplied

- [ ] Seller legal identity and authority to sell
- [ ] Contributor list, employment/contractor inventions assignments
- [ ] Complete Git history and prior license/public-distribution analysis
- [ ] Trademark/name clearance report
- [ ] Dependency and model license opinion
- [ ] Schedule of excluded assets and third-party materials
- [ ] Litigation, claims, security incidents, and encumbrance disclosure

## Technical evidence — repository supplied

- [x] Current source-only tree separated from unrelated research project
- [x] Automated unit/API/security/orchestration test suite
- [x] Python 3.10–3.12 CI and package build
- [x] Static lint/security and dependency vulnerability scans
- [x] Wheel/sdist packaging and clean-environment smoke test
- [x] Security policy and release checklist
- [x] Immutable model revision manifest workflow
- [ ] Real-model quality/performance benchmarks on advertised hardware profiles
- [ ] Independent penetration-test report
- [ ] Signed native installers and update/rollback evidence
- [ ] SBOM and exact final dependency lock

## Product demonstration script

1. Start Zehnora in default offline mode.
2. Demonstrate malformed Arabic/English intent routing.
3. Load a buyer-approved local model profile.
4. Run a bounded research job against approved public sources.
5. Ask a connected multi-source question and inspect citations.
6. Show authentication, rate limits, SSRF blocking, workspace confinement, and
   disabled command execution.
7. Build and install the clean wheel.
8. Re-run CI/tests from the exact proposed closing commit.

## Financial/commercial evidence — seller supplied

- [ ] Development cost ledger
- [ ] Hardware/hosting/support cost model
- [ ] Customer interviews, pipeline, revenue, or signed pilots (if any)
- [ ] Proposed valuation and payment structure
- [ ] Transition support scope and cost

Nothing in this index represents that an unchecked item has been completed.
