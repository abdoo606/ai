# Counsel intake checklist for Zehnora asset sale

This file organizes facts for licensed counsel; it is not a substitute for advice.

## Seller and authority

- [ ] Seller legal name, address, citizenship/residence, tax jurisdiction
- [ ] Selling individual/entity and proof of authority
- [ ] Employment, contractor, university, grant, or other invention obligations
- [ ] Contributor identity reconciliation for both Git email addresses
- [ ] AI-assisted-development platform terms and human-authorship assessment

## Title and historical licensing

- [ ] Full repository clone and immutable commit list
- [ ] Historical MIT file and copyright attribution
- [ ] Dates each assistant revision was publicly accessible
- [ ] GitHub terms applicable to a public repository
- [ ] Known clones, downloads, releases, forks, copies, or disclosures
- [ ] Scope of rights seller can assign and exact prior-rights carve-out
- [ ] Drosophila materials removed from current tree but retained in history

## Third-party and product

- [ ] Python dependency license/SBOM schedule
- [ ] Model repository, immutable revision, code license, weight license, and AUP
- [ ] Web content/database rights and runtime-data exclusions
- [ ] Security findings, limitations, and independent-review status
- [ ] “Zehnora” trademark/domain/common-law clearance and transferability

## Definitive transaction

- [ ] Asset Purchase Agreement or IP assignment structure
- [ ] Included/excluded asset schedules and assumed liabilities
- [ ] Representations, warranties, indemnities, caps, survival, and remedies
- [ ] Purchase price, currency, tax allocation, escrow, fees, and release conditions
- [ ] Buyer inspection/acceptance tests and rejection remedy
- [ ] Repository/domain/package/account and secret-transfer mechanics
- [ ] Transition support hours, term, channel, and exclusions
- [ ] Confidentiality, publicity, governing law, disputes, and signatures
- [ ] Seller deletion/retention obligations and closing certificate

## Counsel questions requiring written answers

1. Did the repository-level MIT file cover the assistant code despite its legacy
   copyright line, and what rights may prior recipients retain?
2. Can the seller validly assign copyright/title in AI-assisted portions under the
   relevant jurisdiction and platform terms?
3. What exclusivity statement, if any, can safely be made?
4. Should the repository become private before outreach, and what records must be
   preserved first?
5. Which tax, export, sanctions, consumer, privacy, and foreign-buyer rules apply?
