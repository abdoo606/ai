# Zehnora — private local Arabic/English AI asset

## One-time whole-asset acquisition opportunity

Zehnora is a compact Python-based local intelligence system for teams that want
Arabic/English research, grounded memory, and tool use without sending prompts to
a hosted model provider.

### What is built

- bounded autonomous web research with retained source URLs;
- SQLite FTS5/BM25 memory plus an indexed concept/co-occurrence graph;
- connected evidence retrieval using graph expansion, reciprocal-rank fusion,
  and maximal-marginal-relevance selection;
- Arabic normalization and malformed bilingual intent handling;
- optional local Qwen/Transformers profiles from compact to server class;
- reason → critique → language-specific revision orchestration;
- FastAPI web app, browser voice controls, CLI, local file tools, and guarded
  command execution disabled by default;
- authentication, rate limiting, SSRF protections, workspace confinement,
  package builds, reproducible model manifests, and CI.

- Ruff, Bandit, and dependency audit passing;
- clean wheel installation and live health check verified;
- deterministic source-delivery ZIP with internal and external SHA-256 records.
