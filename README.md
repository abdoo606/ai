# Local Jarvis Assistant

The actively developed product in this repository is [`jarvis/`](jarvis/): an
API-free local personal assistant with Arabic/English model routing, autonomous
research, source-grounded memory, concept-graph retrieval, and optional
multi-pass local reasoning.

- [Jarvis setup and user guide](jarvis/README.md)
- [Security policy](jarvis/SECURITY.md)
- [Commercial release checklist](jarvis/RELEASE_CHECKLIST.md)
- [Developer/agent handoff](jarvis/README_AI.md)

The repository also preserves the imported Drosophila connectome model at the
root. Its original documentation is in [`Readme.md`](Readme.md). The two
projects are intentionally isolated; Jarvis does not alter or depend on the
Drosophila simulation.
